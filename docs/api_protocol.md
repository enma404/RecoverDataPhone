
### الأدوار

| الطرف | الدور |
|-------|-------|
| **التطبيق (Client)** | يستقبل الأوامر، ينفّذها، يرسل النتائج |
| **السيرفر (Server)** | يرسل الأوامر، يستقبل البيانات، يخزّنها |

### المبادئ

- ✅ **JSON** فقط (لا XML، لا Binary).
- ✅ **UTF-8** دائماً.
- ✅ **كل أمر له `id` فريد** (للمطابقة).
- ✅ **الاتصال دائم** (لا يُغلق بعد كل أمر).
- ✅ **Rate Limiting** لكل عميل.
- ✅ **Audit Logging** لكل عملية حساسة.
